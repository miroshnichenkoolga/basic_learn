Контекстные менеджеры

Задание 1: FileWriter
Создан контекстный менеджер через класс (__enter__, __exit__) для открытия и закрытия файла на запись.

Задание 2: time_tracker
Контекстный менеджер с использованием contextlib, измеряющий время выполнения блока кода.

Задание 3: ListContextManager
Контекстный менеджер, возвращающий список в исходное состояние после выхода из блока with. Реализован двумя способами: через класс и через декоратор.

Декораторы
⏱Задание 1: @time_logger
Измеряет и выводит время выполнения функции.

Задание 2: @log_calls
Логирует имя вызываемой функции и её аргументы.

Задание 3: @cache_results
Кэширует результат функции для заданных аргументов и возвращает его при повторных вызовах.

Задание 4: @sleep_decorator(seconds)
Добавляет задержку перед выполнением функции.

Работа с исключениями
1. safe_division(a, b) — безопасное деление с обработкой ZeroDivisionError, 
возвращает результат или None.
2. multiple_exceptions_handling(key1, key2) — обрабатывает KeyError, ValueError, 
ZeroDivisionError при работе со словарём, использует блоки try, except, else, 
finally.
